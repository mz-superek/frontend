Discrete Properties Animations 신규

display, visibility 같은 불연속 속성도 트랜지션 가능 — allow-discrete 키워드

코드
.dp-tip {
  display: none;
  opacity: 0;
  padding: 10px 16px;
  background: var(--surface);
  border: 1px solid var(--accent);
  border-radius: 6px;
  font-size: 0.8rem;
  color: var(--text);
  min-width: 180px;
  text-align: center;
  pointer-events: none;
  position: absolute;
  position-anchor: --dp-anchor;
  bottom: calc(anchor(top) - 8px);
  left: anchor(center);
  translate: -50% -8px;
  transition:
    opacity 0.3s,
    translate 0.3s,
    display 0.3s allow-discrete;
}
.dp-btn:hover + .dp-tip {
  display: block;
  opacity: 1;
  translate: -50% 0;

  @starting-style {
    opacity: 0;
    translate: -50% -8px;
  }
}
