# AI 튜터와 함께하는 React 심화 학습 자료

이 폴더는 **React를 이미 사용하지만 개념적 깊이가 부족한 프론트엔드 개발자**가 작은 서비스를 바이브코딩으로 구현하면서 React를 제대로 이해하도록 돕는 학습 자료입니다.

핵심은 기능 완성보다 다음 학습 과정을 반복하는 것입니다.

> 사전 예측 → AI 구현 → 코드 설명 → 튜터 문답 → 반례 실험 → 테스트 → 다음 날 재구현

## 문서 구성

### 1. [바이브코딩 기반 React 심화 프로젝트 실행서](./react_vibe_coding_deep_project.html)

가장 먼저 읽을 **주 문서**입니다.

- 6주 학습·구현 순서
- Next.js, NestJS, Supabase PostgreSQL 기반 프로젝트 구조
- 주차별로 추가할 라이브러리와 도입 조건
- 인증·소유권·테스트 기준
- 기능별 바이브코딩 요청문과 병합 조건

프로젝트를 진행할 때는 이 문서의 주차별 순서를 기준으로 삼습니다.

### 2. [AI로 React 깊게 공부하는 실전 가이드](./react_ai_study_guide.html)

구현 중 개념이 막힐 때 찾아보는 **React 개념 참고서**입니다.

- state, render, event, effect의 관계
- 최소 state와 derived state
- closure, race condition, Effect와 Ref
- AI 답변을 그대로 믿지 않고 검증하는 방법
- 예측·설명·변형·디버깅 중심의 학습법

처음부터 전부 외우지 말고, 실행서에서 해당 주차를 진행하며 필요한 개념 모듈만 함께 읽습니다.

### 3. [학습 문서·튜터 스킬 변경 설명과 퀴즈](./2026-08-27-react-study-review-fixes.html)

두 학습 문서와 튜터 스킬이 어떤 기준으로 구성됐는지 확인하는 **보충 문서**입니다.

- 문서별 역할과 규칙을 나눈 이유
- 인증·보안·라이브러리 구성을 보강한 내용
- 적용한 검증 결과
- 핵심 내용을 확인하는 5개 퀴즈

필수 진도는 아니며, 전체 구조를 이해하거나 자료를 다른 사람에게 설명하기 전에 읽으면 됩니다.

## 권장 읽기 순서

1. 실행서의 **학습 원칙, AI 역할, 프로젝트 범위**를 읽습니다.
2. 실행서의 **현재 주차**에서 구현할 기능과 학습할 React 개념을 확인합니다.
3. 개념 참고서에서 해당 개념 모듈만 읽습니다.
4. 작은 기능 하나를 구현하고 React 튜터로 이해도를 점검합니다.
5. 한 주가 끝나면 변경 설명서의 퀴즈로 전체 원칙을 복습합니다.

## 기능 하나를 학습하는 방법

### 1. 구현 전에 예측하기

코드를 만들기 전에 다음 내용을 직접 적습니다.

```text
변하는 값:
state로 저장할 값:
계산 가능한 값:
상태 소유자:
예상 렌더링:
필요한 Effect와 외부 시스템:
예상 실패 상황:
```

### 2. 구현 AI에 작은 범위만 요청하기

```text
이 기능만 작은 diff로 구현해줘.
구현 전에 state와 데이터 흐름을 설명해줘.
불필요한 state, Effect, memoization, 추상화는 추가하지 마.
관련 테스트를 먼저 작성하고 실패를 확인해줘.
```

한 번에 화면 전체를 만들지 말고, 로그인·프로젝트 생성·검색 필터처럼 설명 가능한 크기로 나눕니다.

### 3. 생성된 코드를 직접 설명하기

다음 질문에 답하지 못하면 아직 학습이 끝난 것이 아닙니다.

- 어떤 값이 state이며 왜 필요한가?
- 어떤 값은 기존 값에서 계산할 수 있는가?
- 이벤트가 실행되면 어떤 렌더링이 발생하는가?
- Effect가 있다면 어떤 외부 시스템과 동기화하는가?
- 조건이나 실행 순서가 바뀌면 결과가 어떻게 달라지는가?

### 4. React 튜터 호출하기

기능의 diff가 준비되면 다음처럼 명시적으로 호출합니다.

```text
$react-concept-tutor 현재 이슈 필터 diff로 개념을 점검해줘.
```

튜터는 한 번에 한 질문만 제시합니다. 첫 오답에는 힌트를 받고 다시 답하며, 두 번째 오답에는 원리 설명을 들은 뒤 변형 문제를 풉니다. 별도로 요청하기 전에는 완성 코드나 수정 코드를 받지 않습니다.

튜터 스킬의 저장소 사본은 [`.agents/skills/react-concept-tutor`](./.agents/skills/react-concept-tutor)에 있습니다.

### 5. 다음 날 AI 없이 재구현하기

전체 기능을 다시 만들 필요는 없습니다. 튜터 평가에서 지정한 핵심 부분만 빈 파일이나 별도 브랜치에서 다시 구현합니다.

예:

```text
설명: 통과
예측: 보완 필요
변형: 통과
디버깅: 오개념 발견
재구현 과제: 검색 필터 상태를 AI 없이 구현
```

## 주간 운영 방법

- 한 기능당 작은 PR 하나로 진행합니다.
- 테스트는 6주차로 미루지 않고 해당 기능을 구현할 때 작성합니다.
- 라이브러리는 실행서에 적힌 도입 조건이 실제로 생겼을 때만 추가합니다.
- React 개념 설명은 실행 결과와 React 공식 문서를 함께 확인합니다.
- 기능 완성만으로 병합하지 않고 설명·튜터 문답·재구현까지 확인합니다.

## 시작하기

1. [프로젝트 실행서](./react_vibe_coding_deep_project.html)를 브라우저로 엽니다.
2. 1주차 범위와 구현 전 작성 양식을 확인합니다.
3. 작은 기능 하나를 정해 예측부터 시작합니다.
